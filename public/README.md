# Романтическое приглашение — сайт + Telegram-уведомления

## Что внутри
- Адаптивный сайт для телефона и компьютера.
- Вопросы по заданному сценарию.
- На первом экране «Нет» ведёт к «Ты уверена?».
- На втором экране кнопка «Нет» неактивна.
- После заполнения формы сайт отправляет ответы в Telegram-чат, указанный через `TELEGRAM_CHAT_ID`.
- Токен бота хранится только на сервере, а не в браузере.

## Важное ограничение Telegram
Telegram Bot API не позволяет боту начать личный диалог с произвольным `@username`. Получатель должен сначала открыть созданного бота и нажать **Start**. После этого сервер сможет отправлять уведомления в его числовой `chat_id`.

## Настройка
1. В Telegram откройте `@BotFather`, отправьте `/newbot` и создайте бота.
2. Скопируйте выданный токен.
3. Скопируйте `.env.example` в файл `.env` и вставьте токен в `TELEGRAM_BOT_TOKEN`.
4. Установите зависимости: `npm install`.
5. Запустите проект: `npm start`.
6. Откройте `http://localhost:3000`.
7. Чтобы узнать `chat_id` получателя: откройте своего нового бота в Telegram, нажмите **Start**. Бот пришлёт число `chat_id`.
8. Вставьте это число в `TELEGRAM_CHAT_ID` в `.env`, перезапустите сервер.

## Публикация в интернете
Для доступа с телефона другого человека проект нужно разместить на хостинге с поддержкой Node.js (например, Render, Railway или VPS). Переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` задаются в настройках хостинга. Используйте HTTPS.

## Проверка
Перед отправкой ссылки проверьте сайт на телефоне и отправку тестового ответа. Не публикуйте токен бота и не вставляйте его в `public/` файлы.
